# LinkedIn Post

🌍📻 Excited to share my latest project: World Radio!

I've built an interactive web app that lets you explore and listen to radio stations from around the globe. Whether you're curious about local broadcasts or want to discover new music, this tool makes it easy.

Key features:
• Interactive world map with station locations
• Radio scanner to tune through frequencies  
• "Surprise Me" for random station discovery
• Real-time streaming with HLS.js support

Built with TypeScript, Vite, Leaflet maps, and the Radio Browser API. Fully responsive and deployed on GitHub Pages.

Check it out: https://roberjo.github.io/world-radio/
